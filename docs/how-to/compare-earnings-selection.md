# 決算を使った銘柄選びを合成データで比較する

リポジトリのルートで、架空の銘柄・時刻・価格を使った1日分の比較を実行します。

```sh
python -B -m research.python.earnings_selection.demo
python -B -m unittest discover -s research/python -t research/python -v
```

初回の合成検証では、日本時間18:00を判断締切とし、両方の選定に共通する価格・流動性条件を設定します。100株の終値ベースの代金が50万円以内で、過去20営業日の平均売買代金が5,000万円以上の銘柄が対象です。平均売買代金は確定済みの市場データの集計値を入力します。

決算側は判断日に人が根拠付きで確定した候補を確定時刻順に採用します。対照は同じ母集団から平均売買代金の降順で選びます。いずれも各1枠で、同点は銘柄コード順です。候補は判断締切までに利用できた資料に基づきます。

両グループで翌営業日の始値を参入価格、参入から10営業日後の始値を退出価格とします。費用は合成検証用の往復10 bpを参入代金に1回適用し、銭に切り上げます。出力の金額は銭です。予定・評価済み・不明の件数を確認できます。始値が欠けた場合は元の候補を保持し、損益を `null` とします。両方が同じ銘柄を選んだ場合は `shared_symbol` に記録されます。

実データで判断する際の開示の可用性、費用、評価期間は別途定めます。設計の経緯は[公開Issue #14](https://github.com/kiraemon/japan-stock-trading-lab/issues/14)にあります。
